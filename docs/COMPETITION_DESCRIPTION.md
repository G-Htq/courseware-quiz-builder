# 参赛作品简介（≤500 字）

**作品名称**：课件智练——AI课件出题与智能复习 Skill（courseware-quiz-builder v2.2）

**一句话**：把 PPT/PDF/Word/笔记变成每题可溯源的复习题库与单文件离线刷题页；
伪造出处、材料被替换、证据缺失都会被机器门禁拦下，无法冒充"已验证"。

**解决的真实问题**：大学生复习最缺"能刷、能查、可信"的题。市面工具要么题目无出处，
要么答案可能就是幻觉。课件智练让每题携带材料原文引用（segment_id+逐字引用），脚本
逐题定位核验，出处自动生成规范页码，AI 语义复核三态诚实标注。

**核心创新**：

1. **逐题门禁**：一题缺证据即阻断，不能借其他题通过而放行；展示引用与真实定位交叉
   核对（伪造"第999页"即 FAIL）；材料 SHA-256 完整性核验，替换材料逃不过。
2. **三维状态契约**：验证结论/发布状态/检查执行状态分离，报告机器可读，
   blocked 恒等 BLOCKED，退出码不撒谎。
3. **证据链三层验证**：结构质检→来源定位→AI 语义复核；短证据给质量标记而非
   笼统"全部通过"。
4. **原子化构建**：失败零半成品，旧正式产物保留并整版警告，不误毁已验证成果。
5. **学习闭环**：考试状态机（新卷新 ID/刷新恢复/旧卷快照）、错题前后对比、
   考点掌握度、记录 Schema 校验导入导出；刷题页单 HTML 全离线。

**真实工作量**：113 项自动化测试全绿、32 场景真实浏览器 E2E 全过、9 份真实课件
（2845 片段）解析全成功、0 高风险安全扫描。技术方案与验证数据见 docs/ 目录。
