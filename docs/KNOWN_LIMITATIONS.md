# KNOWN_LIMITATIONS - 已知限制与未验证项（诚实申报）

## 一、平台级未验证项（L3，本开发环境无 TeleAgent 桌面客户端）

以下为**明确未验证**的能力，不作任何宣称；人工验收步骤见
`tests/e2e/E2E_CHECKLIST_V22.md` 文末 L3 清单与 `docs/PLATFORM_ACCEPTANCE.md`：

| # | 未验证项 | 原因 | 建议验收方式 |
|---|---|---|---|
| 1 | 对话自然语言触发命中率（正向触发词、反向不误触） | 无桌面端会话环境 | 在 TeleAgent 中输入 ≥5 条正向说法与 ≥5 条无关说法观察是否命中/误触 |
| 2 | 技能注册后宿主加载与技能列表展示 | 注册 API 已返回成功（Register success），但无客户端可查看 | 桌面端技能页确认可见且启用，删一次重导验证 |
| 3 | 真实大型课件（>50MB PPTX/PDF）端到端耗时与内存 | 已实测 9 份真实材料中最大单件约 2.4MB；>50MB 未测 | 用 >50MB 课件跑完整九步流程记录耗时与内存峰值 |
| 4 | PDF 扫描件“需 OCR”路径的真实观感 | 真实 PDF（24 学生版）为文本型，无扫描件样本 | 用一份扫描 PDF 触发出题，确认提示诚实不虚构 |
| 5 | file:// 双击场景下的多浏览器差异 | E2E 在 HTTP 服务下执行；刷题页图片为 base64 内嵌理论上不受影响，但未在多浏览器实测 | Chrome/Edge/Firefox 双击打开冒烟 |

## 二、功能边界（设计取舍，非缺陷）

1. **单份试卷回看**：`state.examPaper` 仅保留"当前/最近一份"考试卷快照；再考一次后
   上一卷的逐题回看不再可用（但答题历史 qHistory/attempts 永久保留，错题中心与
   学习报告不受影响）。如需无限试卷归档需引入试卷列表存储，属后续演进项。
2. **层C 语义复核依赖宿主模型质量**：evidence_status 由宿主 LLM 自审写入，脚本只能
   校验其枚举合法与"无证据不得标通过"，无法证明学科正确性——页面已明示
   "规则核验不等于语义绝对正确，重要考点请以教材为准"。
3. **PDF 图片抽取**：v2.0 起依赖 pypdf；v2.2 真实评测的 PDF（24 学生版）为纯文本型，
   仍未以带图 PDF 样例实测（沿用 v2.0 申报）。
4. **超大 data URL 图片**：上限约 20MB（BASE64 后约 28M 字符），超限拒绝内嵌；
   极限值附近的压力测试未做。
5. **多选题复练判分**：多选在复练模式需点"确认答案"判分（单选/判断即时判分），
   交互习惯需用户适应（页面有提示文案）。
6. **真实材料评测的边界**：9 份真实材料均为参赛者本人备考材料，评测覆盖"解析→证据链
   →门禁→产物"工程链路；题库学术内容正确性未做全量人工判卷（8 题中 1 题按诚实原则
   标 needs-review 并保留在产物中，作为"不自称全对"的降级示例）。

## 三、环境依赖

- Python 3 标准库运行核心功能；PDF 文本需 pdfplumber 或 pypdf（缺失时脚本诚实提示
  安装命令，不虚构提取结果）
- 刷题页学习记录依赖浏览器 localStorage；存储被禁用时页面降级为"无持久化+导出兜底"
  （已实测降级横幅）
- Windows 为主开发/测试平台；路径安全在 POSIX 语义下同样成立（resolve+is_relative_to），
  但反斜杠变体拦截用例仅在 Windows 执行过
