# 课件智练——AI课件出题与智能复习 Skill（v2.1）

> 九江市高校首届"星辰杯"TeleAgent 智能体应用创新大赛 · 学习科创类参赛作品
> 技能标识：`courseware-quiz-builder` ｜ 显示名称：课件智练 ｜ 版本：v2.1（质量门禁版）

## 这是什么

把 PPT/PDF/Word/TXT/Markdown 课件与课堂笔记变成**每题可溯源**的复习题库，并生成
**单文件离线刷题页**：复习/考试双模式、逐题解析与来源证据展开、错题重做与前后对比、
按考点的学习报告、学习记录导出导入。全程本地处理，答题记录只存在你的浏览器里。

## v2.1 核心升级：强制质量门禁

**未通过核验的题库，现在无法冒充正式交付物**：

- `build` 默认 strict 门禁：结构失败 / 来源定位失败 / 缺少材料清单 / 语义复核未通过
  → 直接阻断、退出码非零、不产出文件，并清理同题库陈旧产物
- 每次构建/核验都落盘机器可读的 `validation-report.json`（逐条 findings + 逐题三层矩阵）
- 显式 `--mode preview` 才能产出草稿：文件名、MD 头部、页面横幅、报告四处标注
  「草稿·未通过完整核验」，无法被误认为正式交付
- 图片路径安全：`../` 穿越、绝对路径、外链、伪装扩展名一律拦截
- 解析-答案矛盾自动检测（如解析写"故选B"但答案是 A）
- 考试状态机重做：每次开考新试卷 ID、中途刷新恢复、重复交卷守卫、旧卷成绩快照回看
- 学习记录导入 Schema 校验：非法记录拒绝且不动现有状态；v2 旧记录自动迁移

## 产出与用法

技能会交付以下文件（默认在当前工作目录）：

- `题库-<主题>.md`：题目区与答案解析区分离，可打印自测，每题含出处与证据引用
- `刷题页-<主题>.html`：**双击打开即用**（离线单文件，无需联网/安装）
  - 题库首页 → 复习模式（逐题即时反馈）或 考试模式（整卷判分，新卷新 ID）
  - 交卷后：成绩单（试卷 ID/交卷时间）、各考点正确率、错题展开、逐题回看本卷
  - 错题中心：按考点分组、重做本题/全部错题、作答历史前后对比
  - 学习报告：考点掌握度、薄弱点建议、历次成绩、导出/导入学习记录（导入先校验后应用）
  - 支持 ←/→ 切题、数字键选答案、F 标记；手机/平板/电脑自适应
- `validation-report.json`：三维状态契约（validation/release/checks 执行状态）与逐条
  findings（rule_id/severity/suggested_fix），阻断时同样落盘便于修复

## 常见问题

**Q：题目和答案可信吗？**
每题带三层验证：脚本结构质检、来源定位核验（引用能在材料片段中找到）、AI 语义复核；
伪造出处、材料被替换、证据缺失都会被 strict 门禁拦截。页面诚实区分「已核验 /
需人工复核 / 未核验」，不把没验证过的题伪装成已验证。规则核验不等于语义绝对正确，
重要考点请以教材为准。

**Q：支持扫描版 PDF 吗？**
会明确告诉你"需要 OCR"，不虚构识别结果；可走视觉转写路径（由模型看图转述）并注明。

**Q：我的课件会上传吗？**
技能脚本无网络行为，材料仅在本地解析；把材料交给模型处理属于 TeleAgent 宿主运行时
行为（取决于你部署的模型），技能本身不上传任何数据。刷题页完全离线。

**Q：换电脑怎么带走学习记录？**
刷题页「学习报告 → 导出学习记录」生成 JSON 备份，新设备打开刷题页后「导入学习记录」
即可；导入前会做格式校验，非法文件不会污染现有记录。

**Q：需要装什么依赖？**
Python 3 标准库即可运行核心功能；PDF 文本提取需 `pip install pdfplumber`（或 pypdf）。
